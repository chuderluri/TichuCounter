- Settings and the bug report no longer show the git commit hash. It was baked into the APK as a string constant, so the APK depended on the commit it was built from and failed F-Droid's reproducible build check. Version name and version code still identify the build. - The release script now formats, commits and tags before building the APK, and pushes only after the APK has been verified. Anything in the APK that depends on the working tree therefore matches the tagged commit F-Droid rebuilds.
